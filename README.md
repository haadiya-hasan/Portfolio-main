# Haadiya Faruqi — Mauve Serenity × Monochrome Chic Portfolio

A complete, responsive portfolio inspired by the editorial / developer-portfolio structure of [aitezaz.xyz](https://aitezaz.xyz/), redesigned around a **Mauve Serenity × Monochrome Chic** visual system.

## Design direction

- Soft off-white paper background
- Ink-black typography
- Dusty mauve accents
- Editorial serif italics
- Monospace metadata
- Large typography and generous whitespace
- Minimal borders instead of heavy cards
- Subtle grain + dot texture
- Animated orbital AI visual
- Scroll reveal animations
- Responsive mobile layout
- Custom cursor on desktop
- Project artwork generated entirely with CSS, so there are no random stock images cluttering the page

## Run locally

No build system is required.

### Option 1
Open `index.html` directly in a browser.

### Option 2
Use VS Code + Live Server.

### Option 3
From this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Resume

Put your PDF in the project root as:

```text
Resume.pdf
```

The Download CV button already points to that filename.

## Personal links

The email, GitHub and LinkedIn links are already configured. Update them in `index.html` if your URLs change.
